# TradeIQX RAG Module

This folder contains the knowledge retrieval system for the TradeIQX AI chatbot.

## Components

- `tradeiqx_knowledge.json` - Trading knowledge base
- `tradeiqx_retriever.py` - Semantic search and RAG retrieval system

## Features

- Semantic search using embeddings
- Similarity-based filtering
- Difficulty-based personalization
- RAG context generation
- Confidence scoring
